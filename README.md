# UP Medicine Transparency Demo

Next.js demo inspired by the public transparency workflow described in the supplied Navbharat Times article. It is not an official FSDA portal and uses sample data.

## Demo credentials
- Email: `admin@demo.local`
- Password: `Demo@1234`

## Run
npm install
npm run dev

## Deploy
Works on Vercel as a static/server-rendered Next.js demo. For production persistence, replace `lib/data.ts` with a Postgres/Neon/Supabase repository and use secure auth/session cookies.
